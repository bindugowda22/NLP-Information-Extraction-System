NLP Information Extraction System - Fixed Project

1. Open this folder in VS Code.
2. Open Terminal.
3. Run:
   python -m pip install -r requirements.txt

4. Run:
   python -m spacy download en_core_web_sm

5. Run:
   python download_nltk.py

6. Start the application:
   python -m streamlit run app.py

You can also double-click run_app.bat after installing the dependencies.

The project includes a small sample dataset at:
dataset/train.csv

If you have the original/full train.csv, replace the sample file with it.
