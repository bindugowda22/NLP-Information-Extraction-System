\# 🧠 Information Extraction System Using NLP



An NLP-based Information Extraction System developed using Python, Streamlit, spaCy and NLTK.



The system extracts meaningful and structured information from unstructured text and presents the results through an interactive web dashboard.



\---



\## 📌 Project Overview



Natural Language Processing (NLP) enables computers to process and understand human language.



This project focuses on Information Extraction from text using multiple NLP techniques.



The system provides the following functionalities:



\- 📝 Part-of-Speech (POS) Tagging

\- 🏷️ Named Entity Recognition (NER)

\- 🔗 Relation Extraction

\- 📅 Event Extraction

\- ⏳ Temporal Ordering / Timeline

\- 🌐 Knowledge Graph Generation



Users can either select text from the dataset or enter their own custom text for analysis.



\---



\## 🎯 Objectives



The main objectives of this project are:



1\. Extract useful information from unstructured text.

2\. Identify grammatical categories of words.

3\. Detect important named entities.

4\. Extract relationships between entities.

5\. Identify events and actions from text.

6\. Detect and organize temporal information.

7\. Represent extracted relationships using a knowledge graph.

8\. Provide an interactive and easy-to-use NLP dashboard.



\---



\## ✨ Features



\### 📝 POS Tagging



Identifies the grammatical category of each word.



Example:



| Word | POS |

|------|-----|

| Apple | PROPN |

| launched | VERB |

| a | DET |

| product | NOUN |



\---
